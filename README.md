# EV ENGINE

Звук двигуна для вашого електрокара — веб‑додаток, що перетворює тихий електромобіль на спорткар
на слух водія. Відкривається у браузері авто (Tesla, Rivian, Polestar) або на телефоні.

- **Без жодного семпла** — звук двигуна синтезується в реальному часі (AudioWorklet) на пристрої.
- **6 двигунів**: V12 Суперкар, Італійський V8, Flat‑6 GT, V8 Muscle, Рядна шістка Turbo, F1 V10.
- **Оберти за швидкістю** — з GPS або демо‑поїздки; передачі, навантаження й постріли рахуються як у ДВЗ.
- **PWA** — ставиться на головний екран, працює офлайн.
- **UA / EN** — перемикання без перезавантаження.

## Запуск локально

```bash
python3 -m http.server 8777
# відкрити http://localhost:8777/
```

## Структура

| Файл | Призначення |
|---|---|
| `js/synth-dsp.js` | модель двигуна (імпульси за кутом колінвала, труби, глушник, постріли, турбо) |
| `js/engine-worklet.js` | AudioWorklet‑обгортка DSP |
| `js/synth-audio.js` | граф Web Audio (EQ, реверб, компресор) |
| `js/audio-out.js` | розблокування звуку, маршрут direct / media player |
| `js/drivetrain.js` | передачі, оберти, навантаження, постріли на скиданні |
| `js/speed.js` | швидкість з GPS або демо |
| `js/gauges.js` | SVG‑кластер (дві шкали / портрет) |
| `js/app.js` | екрани, ігровий цикл, меню |

Увага: за кермом відповідальність на водієві. Тримайте гучність такою, щоб чути трафік.
